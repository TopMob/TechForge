# Unified system unit database: power supplies

This directory contains a single unified structure for system unit power supplies.

## Files

- `schema.json` — collection schema for the unified database.
- `catalog.json` — merged power supply records from available folders in `BD`.

## Source folders

- `BD/pc-part-dataset-main/data/csv`
- `BD/pc-part-dataset-main/data/json`
- `BD/pc-part-dataset-main/data/jsonl`
