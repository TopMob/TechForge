# Структура базы комплектующих

## Категории

- `CPU` — процессоры по производителям:
  - `AMD.json`
  - `INTEL.json`
- `GPU` — видеокарты по производителям:
  - `AMD.json`
  - `INTEL.json`
  - `NVIDIA.json`
  - `OTHER.json`
  - `ALL_GPU.csv` — общий CSV-список
- `RAM` — оперативная память по поколениям:
  - `ddr2.json`
  - `ddr3.json`
  - `ddr4.json`
  - `ddr5.json`
  - `RAW/` — дополнительные исходные форматы (`csv`, `jsonl`)
- `MOTHERBOARDS`:
  - `motherboards.json`
- `POWER_SUPPLIES`:
  - `power_supplies.json`
