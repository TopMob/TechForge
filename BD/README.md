# TechForge BD

Единая база данных комплектующих для платформы подбора, сравнения и обучения сборке ПК.

## Для чего эта база

`BD` — это прикладной каталог компонентов, подготовленный для веб-сайта с тремя ключевыми сценариями:

- глубокое сравнение характеристик и производительности комплектующих;
- конфигуратор сборки ПК с расширенными фильтрами совместимости и подбора;
- интерактивное пошаговое руководство по сборке и апгрейду системы.

Все файлы в структуре оставлены только в полезном рабочем формате `json`, чтобы данные можно было сразу подключать на сайте без конвертаций.

## Структура каталога

- `CPU`
  - `AMD.json`
  - `INTEL.json`
- `GPU`
  - `AMD.json`
  - `INTEL.json`
  - `NVIDIA.json`
  - `OTHER.json`
- `RAM`
  - `ddr4.json`
  - `ddr5.json`
- `MOTHERBOARDS`
  - `motherboards.json`
- `POWER_SUPPLIES`
  - `power_supplies.json`

## Принципы организации

- данные разделены по типу компонентов и брендам;
- названия файлов короткие, однозначные и удобные для программного доступа;
- в каталоге нет дублирующих, пустых или промежуточных форматов;
- структура готова для масштабирования: можно добавлять новые категории и бренды без изменения общей схемы.
