# TechForge roadmap (следующий проход)

## Что вынесено в следующий этап
- Guided flow мастера сборки по шагам (бюджет → сценарий → приоритеты → автоподбор).
- Полный анализ «почему сборка плохая» с тремя наборами исправлений: минимально, оптимально, без роста бюджета.
- Отдельный режим сравнения сборок A/B с дельтой цены, мощности, энергопотребления и апгрейд-потенциала.
- Расширенная диагностика периферии: ghosting/multi-key rollover, mouse latency approximation, phase/volume sweep аудиотест.
- View Transitions API для анимации переходов между вкладками и карточками.

## Почему отдельно
Эти части требуют дополнительной декомпозиции UI и выделения расчётных сервисов/воркера, чтобы сохранить текущую модульность и не превратить `techforge.js` в монолит.
