# TechForge roadmap (следующий проход)

## Что уже закрыто
- Guided flow мастера сборки по шагам (бюджет → сценарий → приоритеты → автоподбор).
- Блок анализа «почему сборка плохая» с тремя наборами исправлений.

## Что вынесено в следующий этап
- Полный режим сравнения сборок A/B с дельтой цены, мощности, энергопотребления и апгрейд-потенциала.
- Расширенная диагностика периферии: ghosting/multi-key rollover, mouse latency approximation, phase/volume sweep аудиотест.
- View Transitions API для анимации переходов между вкладками и карточками.

## Почему отдельно
Следующие части требуют дополнительной декомпозиции состояния UI и выделения тяжёлых расчётов в worker, чтобы сохранить модульную архитектуру.
