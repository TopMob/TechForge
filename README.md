SmartNotes 📝

Современное веб-приложение для создания заметок с облачной синхронизацией и гибкой настройкой интерфейса.

## Основные функции
- Управление заметками: создание, архивация и тегирование
- Облачное хранилище: авторизация и сохранение данных
- Персонализация: выбор цветовых тем и настройка оформления
